# 图片导入插件

把常见格式的图片导入 ScholaRust 文库。安装后，左栏「按格式」筛选里会出现 **图片** 一栏。

## 支持格式

PNG、JPG/JPEG、WebP、BMP、GIF、TIFF（按文件后缀识别；无后缀时按文件头签名识别）。

## 使用

1. 在「扩展」面板导入 `image-import.zip`。
2. 左栏「打开文件」选择图片，或把图片拖入文件对话框。
3. **原文** 视图直接显示图片；**阅读** 视图按图片块展示，图片说明可逐块翻译。

## 限制

- 单张图片约 **1.5MB** 以内可直接显示；更大的图片会提示压缩后重新导入（宿主对插件内嵌图片有大小上限）。
- 图片按原样嵌入文档，不会上传到网络。
